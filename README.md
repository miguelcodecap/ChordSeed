# Chordseed

*Every song begins as a seed.*

Chordseed is a web app for songwriters and musicians: build chord progressions,
hear them on real instruments, see how to play them, learn the theory behind them
and discover famous songs that use the same chords.

Created in Nevada, USA. © 2026 Chordseed. All rights reserved.

## Features

- **Chord generator**: start from your chords and get the best next chord for the mood you want, with explanations.
- **Enrich my chords**: sevenths, substitutions and passing chords by style.
- **Scales for your melody**: which notes to play over each chord.
- **Change key**: modulate from one key to another.
- **Chord dictionary**: every chord, every shape, or identify a chord from the notes you press.
- **Tuner**: tune with your microphone.
- **Learn from scratch**: 7 short lessons with sound and a quiz, guided by **Lumen**, the lantern alchemist.
- Song structure builder, example songs, backing band, 7 languages (opens in English by default).

## Run it

It is a static site: no build step, no server code.

```bash
# from this folder
python3 -m http.server 8000
# open http://localhost:8000
```

> Opening `index.html` by double-click (file://) shows the app, but browsers block
> loading the instrument samples from disk. Use a local server or GitHub Pages.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Branch: `main`, folder: `/ (root)` → **Save**.
4. After a minute your app is live at `https://<your-user>.github.io/<repo-name>/`.
   Share that link: anyone can use it, no account needed.

## Project structure

```
index.html            Built app (generated by build.py — do not edit by hand)
runtime/dc-runtime.js Tiny runtime that renders the app templates in any browser
src/Main.dc.html      App source (template + logic), as edited on claude.ai
src/Diagram.dc.html   Chord-diagram component
assets/img/           Logo and Lumen character poses
assets/samples/       Instrument samples (FluidR3 GM, CC BY 3.0)
build.py              Rebuilds index.html from src/
```

## Updating

1. Edit `src/Main.dc.html` (or update it from the claude.ai artifact).
2. Run `python3 build.py`.
3. Commit and push. GitHub Pages redeploys automatically.

If you add a new image or sample in the artifact, add its asset id → file path to
the `ASSETS` map in `build.py`.
